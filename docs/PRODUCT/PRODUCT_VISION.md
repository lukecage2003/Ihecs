# Vision produit — IHECS STUDY OS

## Mission

Un environnement universitaire personnel, privé et fiable, qui accompagne tout le cursus à l'IHECS : organiser, comprendre, mémoriser, s'entraîner, préparer les examens écrits et oraux, développer les compétences journalistiques et de communication, et garder l'historique complet des années d'études.

C'est **une plateforme d'étude structurée**, pas un chatbot. Elle doit être pleinement utile **sans IA**.

## Principes non négociables

1. Aucune fonction essentielle ne dépend de l'IA ; l'IA est désactivée par défaut.
2. Aucun coût caché, aucun appel payant automatique.
3. Aucun document académique exposé publiquement ; les originaux ne sont jamais modifiés.
4. Aucune donnée supprimée en silence ; pas de migration destructive sans accord explicite.
5. Chaque résultat d'apprentissage se rattache à une activité réelle ; chaque ressource garde ses références de source.
6. On n'annonce pas qu'une fonctionnalité marche tant que son parcours n'a pas été testé.

## Environnement autorisé

- **Code** : dépôt GitHub privé (source de vérité du code), GitHub Actions pour les vérifications, GitHub Pages pour l'hébergement statique si le forfait et la visibilité le permettent.
- **Données** : Google Drive (stockage principal, synchronisation bidirectionnelle), via les API Google officielles et le scope minimal.
- **Interdit** : tout autre hébergement, base de données, stockage d'objets ou serveur permanent.

## Utilisateur

Un·e étudiant·e de l'IHECS (bachelier, puis master), francophone, qui travaille sur ordinateur et sur téléphone, avec des examens écrits, oraux et pratiques (journalisme, communication).

## Modules cibles

Structure académique · Bibliothèque de documents · Connaissances et notes · Study Lab · Moteur de répétition espacée (FSRS) · Exam Center · Writing Studio · Oral Academy · Journalism Lab · Planificateur · Analytique de performance · Content Studio · IA optionnelle.

## Mesures de réussite

- Révisions faites à temps (taux de fiches dues effectivement revues).
- Rétention mesurée (rappel réussi après un intervalle), par matière et par chapitre.
- Résultats aux examens blancs, avec leur tendance.
- Aucune perte de données, et une restauration vérifiée.
- Usage quotidien rapide : moins de 3 secondes pour ouvrir la file du jour.

## Hors périmètre (pour l'instant)

Fonctions collaboratives, partage public, notifications quand le site est fermé, IA automatique, application mobile native.

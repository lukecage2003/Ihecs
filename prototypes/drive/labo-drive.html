IHECS STUDY OS · Prototype option A

Laboratoire Google Drive

Ce fichier vérifie, sur ton ordinateur, si le site peut utiliser un dossier synchronisé par Google Drive pour ordinateur. Fais les expériences dans l'ordre, puis copie le rapport et envoie-le dans la conversation.

Sécurité. Le laboratoire n'écrit que dans un sous-dossier _labo-ihecs du dossier que tu choisis, ne lit rien d'autre, ne supprime aucun fichier et n'envoie rien sur Internet.

0. Compatibilité du navigateur

…

1. Choisir le dossier

Aucun dossier
  1. Dans Google Drive pour ordinateur, ouvre le dossier « Mon Drive » sur ton ordinateur et crée un dossier vide IHECS STUDY OS.
  2. Clique sur le bouton ci-dessous et choisis ce dossier. Chrome demande l'autorisation de modifier : accepte.

2. L'autorisation survit-elle à un redémarrage ?

À faire
  1. Après l'étape 1, ferme complètement Chrome (toutes les fenêtres).
  2. Rouvre ce fichier. Le résultat s'enregistre automatiquement à l'ouverture.
  3. Si possible, recommence le lendemain ou après un redémarrage de l'ordinateur.

3. Ordinateur → Drive : délai

À faire
  1. Clique sur « Écrire un fichier ». Il est créé dans _labo-ihecs/sortant.
  2. Ouvre drive.google.com (ou l'application Drive du téléphone) dans ce dossier et actualise.
  3. Dès que le fichier apparaît, clique sur « Je le vois dans Drive ».

4. Drive → ordinateur : délai

À faire
  1. Clique sur « Démarrer l'attente ».
  2. Sur drive.google.com ou le téléphone, ajoute un fichier quelconque (photo, PDF, note) dans IHECS STUDY OS/_labo-ihecs/entrant.
  3. Le laboratoire vérifie toutes les 2 secondes et mesure le délai d'arrivée (10 minutes au maximum).

5. Modifications simultanées

À faire
  1. Clique sur « Préparer » : le fichier _labo-ihecs/partage.json est créé. Attends qu'il apparaisse sur drive.google.com.
  2. Dans Google Drive pour ordinateur, suspends la synchronisation (menu de l'icône Drive, puis Réglages).
  3. Clique sur « Modifier côté ordinateur ».
  4. Clique sur « Télécharger la version web », puis importe ce fichier sur drive.google.com dans _labo-ihecs. S'il s'appelle partage (1).json, renomme-le d'abord partage.json. Si Drive demande, choisis Remplacer.
  5. Reprends la synchronisation, attends une minute, puis clique sur « Analyser ».

6. Rapport

Le rapport contient ton navigateur, ton système, le nom du dossier choisi et les noms des fichiers de _labo-ihecs. Aucun autre contenu.
